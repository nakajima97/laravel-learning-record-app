# ドキュメント

このディレクトリには、学習記録アプリケーションの設計・仕様に関するドキュメントが含まれています。

## ドキュメント一覧

### [functional_requirements.md](./functional_requirements.md)
アプリケーションの機能要件を定義したドキュメントです。
- ユーザー管理機能
- 学習記録機能
- カテゴリー管理機能
- 統計・分析機能

### [database_design.md](./database_design.md)
データベース設計に関するドキュメントです。
- テーブル定義
- ER図
- リレーションシップ

### [screen_ui_specifications.md](./screen_ui_specifications.md)
画面・UI仕様を定義したドキュメントです。
- 各画面のレイアウト
- UIコンポーネント
- 画面遷移

### [issues_and_improvements.md](./issues_and_improvements.md)
既知の問題点と改善提案をまとめたドキュメントです。
- 課題リスト
- 改善案
- 優先度

## ドキュメントの更新について

プロジェクトの仕様や設計に変更があった場合は、該当するドキュメントを更新してください。
