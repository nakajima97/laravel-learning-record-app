# 機能要件書

## 1. システム概要

学習記録管理アプリケーション

ユーザーが日々の学習時間を記録し、カテゴリ別に管理・集計するためのWebアプリケーション。

## 2. 主要機能

### 2.1 認証機能

- **ユーザー登録**
  - 名前、メールアドレス、パスワードで新規ユーザーを登録
  - メール認証機能

- **ログイン/ログアウト**
  - メールアドレスとパスワードによる認証
  - ログイン状態の維持（Remember Me）

- **パスワードリセット**
  - メールアドレスによるパスワードリセットリンクの送信
  - 新しいパスワードの設定

- **プロフィール管理**
  - ユーザー情報の更新（名前、メールアドレス）
  - パスワード変更
  - アカウント削除

### 2.2 カテゴリ管理機能

#### 2.2.1 メインカテゴリ管理

- **カテゴリ一覧表示**
  - ログインユーザーが作成したメインカテゴリの一覧を表示
  - 各カテゴリに紐づくサブカテゴリも表示

- **カテゴリ作成**
  - メインカテゴリ名を入力して新規作成
  - 作成したカテゴリは自動的にログインユーザーに紐付け

#### 2.2.2 サブカテゴリ管理

- **サブカテゴリ作成**
  - サブカテゴリ名とメインカテゴリを選択して新規作成
  - メインカテゴリのドロップダウンリストから選択

### 2.3 学習記録機能

- **記録一覧表示**
  - 今日の学習記録を一覧表示
  - 今日の合計学習時間を表示
  - 今月の合計学習時間を表示
  - 各記録には以下の情報を表示：
    - サブカテゴリ名
    - メインカテゴリ名
    - 学習時間（分）
    - メモ
    - 記録日時

- **記録作成**
  - サブカテゴリを選択
  - 学習時間（分）を入力
  - メモ（最大256文字）を入力
  - 記録を保存すると自動的にログインユーザーと現在日時に紐付け

### 2.4 ダッシュボード

- ログイン後のホーム画面
- ナビゲーションメニューから各機能へアクセス可能

## 3. 権限とアクセス制御

### 3.1 認証が必要な機能

以下の機能は認証済みユーザーのみアクセス可能：
- ダッシュボード
- 学習記録の作成・一覧表示
- カテゴリ管理（メイン・サブ）
- プロフィール管理

### 3.2 データアクセス制御

- ユーザーは自分が作成したデータのみアクセス可能
- メインカテゴリ：自分が作成したもののみ表示・使用可能
- 学習記録：自分が作成したもののみ表示可能

## 4. バリデーション

### 4.1 学習記録作成時のバリデーション

- **サブカテゴリID**：必須
- **学習時間（分）**：必須、数値、0以上
- **メモ**：最大256文字

### 4.2 ユーザー登録時のバリデーション

- **名前**：必須
- **メールアドレス**：必須、メール形式、一意
- **パスワード**：必須、最小8文字、確認入力と一致

## 5. 集計機能

- **今日の合計学習時間**：当日の全学習記録の時間を合計
- **今月の合計学習時間**：当月の全学習記録の時間を合計

## 6. 画面遷移

```
/ (ルート)
  → /login にリダイレクト

/login
  → 認証成功 → /dashboard

/dashboard (認証必須)
  → ナビゲーションメニュー
    - 学習記録一覧 (/records)
    - カテゴリ一覧 (/categories)
    - プロフィール編集 (/profile)

/records (認証必須)
  - 一覧表示
  - 新規作成 (/records/create)
    → 作成成功 → /records

/categories (認証必須)
  - 一覧表示
  - 新規作成 (/categories/create)
    → 作成成功 → /categories

/sub_categories/create (認証必須)
  → 作成成功 → /categories
```

## 7. 技術仕様

- **フレームワーク**：Laravel（現在のバージョン）
- **認証**：Laravel Breeze
- **データベース**：MySQL/PostgreSQL等のリレーショナルデータベース
- **フロントエンド**：Blade テンプレート
